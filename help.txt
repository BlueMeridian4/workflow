wf <command> [args]   (extra words are passed to Claude commands)

  wf help          show this list
  wf log "msg"     log a change to this project's context   (any AI tool)
  wf decide "choice" "benefit" "cost"   record a decision with its tradeoff
  wf pr "ref" "tldr" "flag"           add a review summary to the board (Claude does this after wf review)
  wf find "name" "what" "url" "take"  add a research finding to the board (wf research does this)
  wf board [path]  open the floating board (decisions + reviews); no path: this repo, or outside a repo the latest one
  wf board --research [path]  open the research window separately
  wf ctx           print this project's context              (any AI tool)
  wf go            resume where you left off              [new terminal window]
  wf research [topic]  open research window, search the web, add findings   [background]
  wf plan [file]   check a plan against .claude/rules.md before coding   [background]
  wf lint          run linters and fix errors             [new terminal window]
  wf lean          slim the current diff (ponytail)       [new terminal window]
  wf review [PR#]  review a PR or branch; never merges    [background]
  wf ship          lint, commit, push, open a PR; never merges   [new terminal window]

[background] runs with no window: results go to the board or ~/.claude/workflow/last-<cmd>.log, and you get a desktop notification.
Your terminal stays free either way.
Inside Claude Code the same tasks are /workflow:go, :plan, :lint, :lean, :review, :ship.
